#### pkg 出包的三个"哑巴坑"（README 级教训，全程退出码 0）
1. **包版本 = App 版本 → payload 被静默跳过**：`productbuild --component` 取 App 的
   CFBundleShortVersionString（2.0.2），与旧收据 `leixlabs.monosub version 2.0.2` 相同，
   Installer 判定"已安装"直接跳过。改用 `pkgbuild --version <编译时刻 yyyyMMddHHmmss>`
   （单调递增），并同步写入 App 的 CFBundleVersion。
2. **Relocation → 装到构建目录自己身上**：`/var/log/install.log` 里
   `PackageKit: Applications/MonoSub.app relocated to .../target/local-sandbox/MonoSub.app`。
   PackageKit 按 bundle id 在全盘找同名 bundle，把安装目标改过去。线索是 PackageInfo 里的
   `<relocate>` / `<upgrade-bundle>` / `<strict-identifier>` / `<atomic-update-bundle/>`。
   修法：pkgutil --expand → 删这几个元素 → --flatten → `productsign` 重签（无命令行开关）。
   注意 pkgbuild 组件包 expand 后是**平铺**的（Bom/PackageInfo/Payload 在根），不是子目录。
3. **`codesign -dv` 不打 Authority**：默认级别只有 Executable/Identifier/TeamIdentifier，
   用 -dv 判断签名身份会恒为假，必须 `-dv --verbose=2`。

#### 环境坑：fs.rmSync 被改写成"移到废纸篓"
本环境的 node 包装带 safe-delete shim，`fs.rmSync` 会走 FSMoveObjectToTrashSync，
对 target/ 产物报 `status -5000` 并中断脚本。脚本内统一改用 `/bin/rm -rf`（hardRemove）。
