## macOS Apple IAP（StoreKit 2）实施

按 `docs/release/macos-iap-plan.md` 实现 Mac App Store 免费下载 + 非消耗型内购：

- 商品：`leixlabs.monosub.pro`，`MonoSub Pro`，$9.99 / ¥48，一次性买断；Family Sharing 开启；已上架老用户用 `AppTransaction.originalAppVersion < 2.1.0` grandfathering 继续免费。

- StoreKit 2：`storekit-rs = "=0.5.2"`，只在 `appstore` Cargo feature（`scripts/release/mas.mjs` 传入 `--features appstore`）下编译；`src-tauri/build.rs` 补 `/usr/lib/swift` 与 Xcode Swift runtime 的 LC_RPATH，否则 dyld 找不到 `libswift_Concurrency.dylib`。
- Debug 无购买测试：`pro_dev_set_state` / `pro_dev_clear_state`，仅 `debug_assertions` 下可改变状态；Settings ▸ 系统 ▸ MonoSub Pro 卡片内显示免费/Pro/待处理/错误按钮。
- 验证：`cargo test --lib` 639 passed / 1 ignored；`cargo test --lib --features appstore` 642 passed / 1 ignored；`bun run check`、`bun run check:i18n`（369 keys）、`bun run lint`（0 error，12 个既有 warning）、`bun run build`、`bun run tauri build --config src-tauri/tauri.mas.conf.json --bundles app --features appstore` 均通过；`bun scripts/release/mas.mjs --skip-build --no-pkg` 用 Mac App Distribution 身份签名通过（CFBundleVersion 6）。
- 待人工：App Store Connect 创建 IAP、App ID 开启 In-App Purchase capability 并重新生成 distribution profile；上架前用 TestFlight/Sandbox 验证真实购买、恢复、退款、Family Sharing。
