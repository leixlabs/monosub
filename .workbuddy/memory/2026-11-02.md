### ITMS-90886：签名缺 application-identifier（手工 codesign 的坑）
症状：Transporter 退回 "Cannot be used with TestFlight because the signature for the bundle ... is missing an application identifier but has an application identifier in the provisioning profile"。
根因：Xcode 会自动把 profile 里的 `com.apple.application-identifier` / `com.apple.developer.team-identifier` 注入签名；我们手工 `codesign --entitlements` 只用了自己写的 plist，于是缺这两项。
修法：
- `src-tauri/entitlements/MonoSub.mas.entitlements` 显式写入两项（RF4CPKUXQ7.leixlabs.monosub / RF4CPKUXQ7）
- `mas.mjs` 签完后拿 profile 里的值逐字核对，缺了直接 fail（防复发）
- 另加 `MAS_BUILD_NUMBER`（默认 3）覆盖 `CFBundleVersion`：Tauri 会把它写成与 version 相同的 2.0.2，同一版本重传会被判"构建已存在"

**坑中坑**：XML 注释里不能出现 `--`，我在注释里写了 `codesign --entitlements`，导致 `AMFIUnserializeXML: syntax error near line 30`（plutil 却检查通过）。
