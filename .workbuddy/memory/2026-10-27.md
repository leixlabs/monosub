# 2026-10-27

## 隐藏 Windows GUI 控制台

- `src-tauri/src/main.rs` 增加 `#![cfg_attr(target_os = "windows", windows_subsystem = "windows")]`，Windows GUI 的 debug/release 启动都不再弹出控制台；独立 CLI 入口不受影响。
- 用户后续仍看到快速闪窗，定位到首屏 `CudaNotice` 自动执行 `nvidia-smi`。在 `commands/gpu.rs` 对 Windows 子进程加 `CREATE_NO_WINDOW`，`cargo check --bin monosub` 通过。

## Windows 自用安装包：`bun run release:exe`（NSIS）

- 新增 `scripts/release/installer.mjs`，`package.json` 加 `release:exe`。区别于面向商店的 MSIX：
  Tauri 自带 NSIS 打包器，产出 `dist\MonoSub_<version>_x64-setup.exe`，双击即装、无需证书/PowerShell。
- `tauri.conf.json` 增加 `bundle.windows.nsis = { installMode: currentUser, compression: lzma }`。
  安装位置 `%LOCALAPPDATA%\MonoSub`，带开始菜单快捷方式、卸载项、`uninstall.exe`。不改 MSIX 流程（它走 `--no-bundle`）。
- 关键顺序：`monosub-cli.exe` 必须在 `tauri build` **之前**落到 `resources\bin\`，否则进不了安装包
  （MSIX 分支是事后手工装配载荷，所以能晚拷）。
- 实测：1.98 GB 载荷 → 1.31 GB 安装包，压缩约 6 分钟，全程 7 分 19 秒。NSIS 数据段上限约 2 GB（压缩后计），
  所以目前刚好够用；再涨就得把重运行时改成下载。
- 实测踩坑：
  - NSIS 工具链下载（GitHub release）经常被代理 502 / TLS 断连；Tauri 还会因为缺
    `Plugins\x86-unicode\additional\nsis_tauri_utils.dll` 判"目录不完整"并重下。手工解压
    `nsis-3.13.zip` 到 `%LOCALAPPDATA%\tauri\NSIS` + 放入该 dll（SHA1 75197fee…）即可跳过。
  - `dist/` 同时是 Vite 的 outDir：`tauri build` 里的 `bun run build` 会清空 dist，旧的 `.msix` 会被静默删除。
    脚本现在构建前会对 `.msix/.msi/.dmg` 打印警告。
- 文档：AGENTS.md 增加 "Windows self-install: NSIS .exe" 小节（三种产物的对照表 + 上述限制）。
