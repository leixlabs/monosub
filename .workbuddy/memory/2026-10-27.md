## 隐藏 Windows GUI 控制台

- `src-tauri/src/main.rs` 增加 `#![cfg_attr(target_os = "windows", windows_subsystem = "windows")]`，Windows GUI 的 debug/release 启动都不再弹出控制台；独立 CLI 入口不受影响。
- 用户后续仍看到快速闪窗，定位到首屏 `CudaNotice` 自动执行 `nvidia-smi`。在 `commands/gpu.rs` 对 Windows 子进程加 `CREATE_NO_WINDOW`，`cargo check --bin monosub` 通过。
- 转录时用户截图显示 Windows Terminal 窗口。对共享启动器 `engine/cli.rs`（audiocpp + VAD）和 `translate/server.rs`（llama-server）设置 Windows `CREATE_NO_WINDOW`；Rust GUI bin 编译检查通过。
- 全面审查进程启动点后，对转录/元数据/缩略图用的 ffmpeg、ffprobe，URL 导入用的 yt-dlp，以及 Windows 的 cmd 链接/文件打开调用补上 `CREATE_NO_WINDOW`；`cargo check --bin monosub` 通过。手动打开系统文件管理器 (`explorer`) 仍会按预期显示窗口。
- 复核时发现并修正自己引入的回退 bug：缩略图 hwaccel 失败后用同一 `Command` 追加 software 参数会叠加两份 argv，改为每次尝试新建命令（`ffmpeg_for_thumbnail`）。`cargo check --all-targets` 通过。
- 缩略图的 `-hwaccel videotoolbox` 原为全平台传入（macOS 专用），Windows 上必然无效再回退，等于每次多跑一次 ffmpeg。改为 `hwaccel_args()` 按平台返回：仅 macOS 有加速前缀，Windows/Linux 直接软件解码。`cargo check --all-targets` 通过。
- 实测（Windows 11，bundled BtbN LGPL 8.1.3）：`-hwaccels` 提供 cuda/dxva2/qsv/d3d11va/d3d12va/amf，单帧缩略图 GPU 反而更慢——720p 148ms(sw) vs 382/315；1080p 160 vs 392/315；4K H.264 296 vs 556/466；4K HEVC 332 vs 560/450（取三次最好值）。`-hwaccel videotoolbox` 在 Windows 直接 exit 127、无输出。故 Windows 保持软件解码是有实测依据的选择，注释已记录数据。

## Windows 自用安装包：`bun run release:exe`（NSIS）

- 新增 `scripts/release/installer.mjs`，`package.json` 加 `release:exe`。区别于面向商店的 MSIX：
  Tauri 自带 NSIS 打包器，产出 `dist\MonoSub_<version>_x64-setup.exe`，双击即装、无需证书/PowerShell。
- `tauri.conf.json` 增加 `bundle.windows.nsis = { installMode: currentUser, compression: lzma }`。
  安装位置 `%LOCALAPPDATA%\MonoSub`，带开始菜单快捷方式、卸载项、`uninstall.exe`。不改 MSIX 流程（它走 `--no-bundle`）。
- 关键顺序：`monosub-cli.exe` 必须在 `tauri build` **之前**落到 `resources\bin\`，否则进不了安装包
  （MSIX 分支是事后手工装配载荷，所以能晚拷）。
- 实测：1.98 GB 载荷 → 1.31 GB 安装包，压缩约 6 分钟，全程 7 分 19 秒。NSIS 数据段上限约 2 GB（压缩后计），
  所以目前刚好够用；再涨就得把重运行时改成下载。
- 实测踩坑：
  - NSIS 工具链下载（GitHub release）经常被代理 502 / TLS 断连；Tauri 还会因为缺
    `Plugins\x86-unicode\additional\nsis_tauri_utils.dll` 判"目录不完整"并重下。手工解压
    `nsis-3.13.zip` 到 `%LOCALAPPDATA%\tauri\NSIS` + 放入该 dll（SHA1 75197fee…）即可跳过。
  - `dist/` 同时是 Vite 的 outDir：`tauri build` 里的 `bun run build` 会清空 dist，旧的 `.msix` 会被静默删除。
    脚本现在构建前会对 `.msix/.msi/.dmg` 打印警告。
- 文档：AGENTS.md 增加 "Windows self-install: NSIS .exe" 小节（三种产物的对照表 + 上述限制）。

## 链接导入：cookie 库读不出来时不再整单失败

- 截图报错 `Could not copy Chrome cookie database. See .../issues/7271`：设置里选了「站点 cookie 来源」，
  yt-dlp 去读 Chrome 的 Cookies sqlite，文件被运行中的 Chrome 锁住（Windows 常见）或 Chrome 127+
  应用绑定加密解不开，于是整个阶段非零退出。公开字幕本来不需要 cookie，却因此整单失败。
- 修法（`site/ytdlp.rs`）：新增 `without_cookies()` 纯函数 + `run()` 内置一次重试——仅当退出非零、
  配置了 cookie、且 stderr 命中 `error::is_cookie_database_failure()` 时，去掉
  `--cookies-from-browser` 重跑同一阶段。`run()` 是唯一出口，resolve / fetch / audio 三处都覆盖。
- `error::is_cookie_database_failure()`：大小写不敏感匹配 `cookie database` / `cookies database` /
  `failed to decrypt with dpapi` / `cookie + failed to decrypt`，并要求同时出现
  `could not|unable to|failed to`，避免无关 `PermissionError` 误丢用户 cookie。
- 设计稿 §4.5 增补该行为一行，并把「这两条匹配串」改为「这些匹配串」。
- 验证：`cargo test --lib site::` 135 通过（新增 3 个用例）；全量 598 通过，仍只有 `engine::vad`
  两个环境相关失败。未做：把「cookie 不可读」做成本会话缓存（会因用户随后关掉浏览器而失效，宁可每次自愈）。

## 链接导入：cookie 不可读 → 无 cookie 重跑 + 支持 cookies.txt（Chrome 127+ 唯一解）

- 第二次截图报 `Failed to decrypt with DPAPI ... issues/10927`：用户关掉 Chrome 后复制成功，但
  **Chrome 127+ 应用绑定加密**让 yt-dlp 解不开（不是锁文件问题，重试/关浏览器都无效）。
- 实测（随包 yt-dlp + 该视频）：**这台机器/出口 IP 上 YouTube 必须带 cookie**，不带就
  `Sign in to confirm you're not a bot`；`--extractor-args youtube:player_client=web_safari|tv|android|ios`
  全都不行，`-F` / `-f ba[ext=m4a]/ba/b` 与取字幕同一条错误 → 「改成下视频」绕不过这个检查，
  因为拦截发生在提取阶段，与要字幕还是音频无关。
- 修法 1（`RunOutput.cookies_unreadable` + `classified()`）：去掉 cookie 重跑后若 stderr 归不到
  具体类别（bot check 就属于这类），报 `urlImport.cookiesUnreadable:<原文>`，文案给出三条出路，
  而不是丢一句英文原文。具体类别（私有/限流）保留原分类。
- 修法 2（真正的解法）：新增 `--cookies <file>` 来源。`Invocation.cookies_file` 优先于
  `cookies_browser`（`build_argv` 只发一个）；`UrlImportRequest.cookies_file`；
  `execute()` 里文件不存在直接报 `urlImport.cookiesFileMissing`；设置页新增「cookies.txt 文件」
  一行（dialog 选 txt）；store 增 `urlImportCookiesFile` 并把 `PERSIST_VERSION` 7→8
  （v7 blob 没有该键，读 `undefined.trim()` 会崩）。
- `allows_fallback` 对 `CookiesUnreadable` 返回 true：只有部分站点把字幕锁在登录后，音频可能是公开的，
  所以仍值得匿名试一次下载；不 retryable。
- 验证：`cargo test --lib site::` 137 通过（新增 `--cookies` 优先级、匿名重跑归类两个用例）；
  `bun run check`、`check:i18n`（342 key 对齐）通过。文档：§4.5 两行 + AGENTS.md 两处同步。
