# MonoSub 双商店定价评估（App Store / Microsoft Store）

> 评估日期：2026-10-26 · 基于仓库 `main` @ bd04a41（v2.0.1）、`docs/tech-spec/microsoft-store-publish-spec.md`
> 汇率：1 USD = 6.689 CNY（2026-10-25）

## 1. 结论

| 项目 | Apple App Store (macOS) | Microsoft Store (Windows) |
| --- | --- | --- |
| 售卖形态 | 免费下载 + **买断内购**（非消耗型 IAP） | 免费下载 + **自有支付**（Polar）买断 |
| 国际价（US 基准） | **$29.99** | **$29.99** |
| 中国区价 | **¥128**（按店面单独覆盖） | **¥128** |
| 首发价（90 天） | $19.99 / ¥68 | $19.99 / ¥68 |
| 抽成 | 15%（小企业计划）/ 30% | 0%（政策 10.8 第三方支付）/ 15%（微软商务） |
| 单笔到手 | $25.49（≈¥170）/ ¥102.6 | $27.54 / ≈¥120 |

不做的事：**不做付费下载**（App Store 付费应用无试用期，且和 GitHub 免费直装版正面冲突）；**不以订阅为主**（离线工具，用户对订阅抵触，且需要持续交付云端价值）。

被否掉的第三档：只做"Pro = 说话人分离"就卖 $29.99。单一功能撑不住，此时价格应为 **$19.99 / ¥88**。

## 2. 定价依据

1. **免费直装版是价格天花板。** GitHub Releases 免费、功能全开，商店版卖的是"已签名/免 Gatekeeper/自动更新/免配置"，不是功能。这类"便利税"在 $20–30 之间，$30 是上限。
2. **竞品锚点。** MacWhisper Pro 直装 €64 买断；它家 MAS 版（Whisper Transcription）$29.99/年 或 $99.99 买断；Superwhisper $84.99/年。$29.99 买断 = 竞品"一年订阅"的钱拿到永久授权，话术清晰、比价不亏。
3. **Pro 增量决定价位。** 现在 README 只写了"说话人分离 + 优先支持"。若 Pro 加宽为 分离 + 本地翻译 + 批量队列 + CLI + 大模型，$29.99 合理；若维持单功能，$19.99。
4. **中国区必须单独定价。** $29.99 按 Apple 均等化约为 ¥198 档，中国个人用户不接受。¥98–128 是国产桌面工具的心理上限，且对云转写（讯飞听见 ~¥0.3/分钟，10 小时≈¥180）有明确 ROI；¥128 到手 ¥102.6。
5. **抽成差异决定渠道优先级。** 同样 $29.99：Windows 自有支付到手 $27.54，Apple 标准 30% 只有 $20.99。差 24%。因此 Windows 侧走 Polar（5% + $0.50 + 国际卡 1.5%），Apple 侧必须走 StoreKit 2。

## 3. 单笔净收入（已计算）

| 价格 | 渠道 | 抽成/税费 | 到手 |
| --- | --- | --- | --- |
| $29.99 | Apple 小企业计划 | 15% | $25.49 |
| $29.99 | Apple 标准 | 30% | $20.99 |
| $29.99 | Microsoft + 微软商务 | 15% | $25.49 |
| $29.99 | Microsoft + Polar | ≈8.2% | $27.54 |
| ¥128 | Apple 中国区 | 6% 增值税 + 15% | ¥102.6 |
| ¥98 | Apple 中国区 | 6% 增值税 + 15% | ¥78.6 |

盈亏平衡参照：¥98 单价、Apple 中国区到手 ¥78.6，月入 1 万元需 ~127 单/月。$29.99 单价、Apple 15%，月入 $1000 需 ~40 单/月。**商店不是发现渠道**，定价的边际收益远小于"Pro 门槛设计 + 商店页质量 + 好评数"。

## 4. 比价格更硬的约束

### Apple
- **3.1.1**：Polar 激活码解锁功能在 MAS 包里一律违规（Apple 明文点名 license keys）。MAS 版必须用 StoreKit 2 内购；Polar 授权链路只能留在直装版。
- **Sandbox**：macOS 商店版必须启用 App Sandbox；`ffmpeg` / `llama-server` / `audiocpp_cli` 等嵌套可执行文件与 dylib 需同一 Team ID 签名，`--deep` 不够。
- **首次运行**：`models/` 只内置 silero_vad，默认模型 sensevoice_small_q8 需联网下载。审核机网络异常时会被判"无法使用"。建议内置一个最小模型，并在审核备注里说明下载源。
- **中国区备案**：新 App 提审中国大陆店面必须填 MIIT ICP 备案号，名称须与备案一致，否则卡在提审。备不下来就先只开海外店面。

### Microsoft
- 政策 **10.8** 允许非游戏应用在 PC 上使用第三方购买 API 且不缴 Store Fee，但要求：提交时在 Partner Center 声明使用第三方购买 API；结账页标明支付提供方并取得用户确认；商店描述中写明"提供应用内购买"。
- MSIX 已在仓库落地（`scripts/windows/build-msix.ps1`、Execution Alias 等），渠道成本最低。

### 许可证（先于定价的阻塞项）
`resources/models.json`（129 个模型）里包含非商用条款：`aya_*`（CC-BY-NC-4.0）、`crisperwhisper_*`（nyra 非商用）、`higgs_audio_v3_*`（研究/非商用，标注"待核对"）、`alma_*`（Llama 2 社区）、`citrinet`（NGC）、`confucius4`（网易有道）。收费即整条链路需可商用：付费版应隐藏/禁用 NC 模型，默认只保留 Apache-2.0 / MIT（SenseVoice、FunASR 条款需单独核对）。

### 现状不一致
`src-tauri/src/commands/external.rs` 注释已说明 Pro 门禁被移除（"personal, non-commercial learning project"），但 README 仍挂 $20 Pro 与 Polar 链接。上架前必须先决定是否重建付费墙——这是 1–2 周工作量，不是定价问题。

## 5. 落地顺序

1. **Microsoft Store 先上**：免费包 + 应用内 Polar 买断（$29.99 / ¥128）。零抽成、打包已就绪、合规成本最低。
2. **App Store**：要么先上纯免费版（不做内购、不提及外部购买），要么补 StoreKit 2 做买断 IAP。中国区先解决备案。
3. **价格实验**：首发 90 天 $19.99 / ¥68（配 Apple Offer Code / MS 限时折扣），之后回到 $29.99 / ¥128；观察退款率与差评口径。
4. 只有在出现真实复购型需求（团队席位、云端备份、批量 API）时再考虑订阅，价格锚 $9.99/月 或 $59/年。

## 6. 修订：若选择「付费下载」（2026-10-26 追加）

决策前提变了：全功能已免费、Pro 门禁已移除、开源/源码公开、只想让商店代收费。此时卖的是**"已编译签名的成品"**，不是功能授权，价格锚随之下移。

| 项目 | 付费下载（推荐值） | 免费 + 内购（对比） |
| --- | --- | --- |
| 售价 | **$9.99**（首发 $6.99）；中国区 **¥48**（首发 ¥30） | $29.99 / ¥128 |
| 上限 | $14.99，超过就几乎没有量 | $29.99–39.99 |
| 抽成 | MS 15% / Apple 15–30% | MS 0%（自有支付）/ Apple 15–30% |
| 单笔到手 | $8.49 / ¥38.5 | $27.54 / ¥102.6 |
| 试用 | MS 支持（1/7/15/30 天）；**Apple 不支持** | Apple 靠免费版替代 |
| 需要写的代码 | 几乎零（Apple 侧零；MS 试用需 StoreContext 读状态） | StoreKit 2 + 授权校验 |
| 主要风险 | "GitHub 免费"差评、Apple 无试用导致退款率高 | 门禁设计、支付链路维护 |

关键修正两条：

1. **付费下载会放弃 0% 抽成。** 政策 10.8 的第三方支付免抽成只适用于「免费应用里的内购」；直接标价收费走微软商务，**15%**。所以"省掉支付维护"实际是用 15% 换的。
2. **Apple 付费应用没有试用期**（免费试用/推介优惠仅订阅可用）。对付办法：先免费上架 1–3 个月攒评分，再改为 $9.99 付费（已下载用户凭购买记录可继续重装）。

上架前仍需处理：仓库**没有 LICENSE 文件**（现状是"源码公开、保留所有权利"，不是开源；若商店页写"开源"需补 MIT/Apache）；ffmpeg 构建 flag 未在 notices 里写死（GPL 构建需提供源码获取方式）；付费版要隐藏 CC-BY-NC / nyra 非商用 / higgs 待核对的模型；中国区 ICP 备案；首启模型联网下载需内置最小模型以通过审核。
